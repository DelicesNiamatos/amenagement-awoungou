# Aménagement Awoungou — Pilote Culture

Maquette 3D interactive et rendu 4K du terrain aménagé du projet **Ferme Niamatos Gabon — Pilote Awoungou**.

## 🌐 Voir en ligne

- **Maquette 3D tous angles** : https://DelicesNiamatos.github.io/amenagement-awoungou/
- **Rendu 4K interactif basé sur l’image retenue** : https://DelicesNiamatos.github.io/amenagement-awoungou/awoungou-4k.html

## À propos

- **Superficie réelle de référence** : 1 500 m² — hypothèse 30 m × 50 m
- **Projet** : Délices Niamatos / Ferme Niamatos Gabon SARL
- **Données source** : Plan de culture et d'aménagement phasé du pilote Awoungou (Notion — DN OS)
- **Modèle principal** : Three.js / WebGL, consultable par rotation, zoom et vues prédéfinies
- **Rendu 4K** : image retenue bonifiée avec zoom, déplacement, animation et repères techniques
- **Déploiement** : GitHub Pages

## Installations / aménagements reflétés

- Habitat conteneurs sur pilotis : 2 conteneurs 20′ parallèles, vide central 3,50 m, hauteur libre 3 m, baies vitrées, balcon-terrasse
- Atelier conteneur + serre légère de toiture
- Puits traditionnel maçonné, pompe solaire, réservoir tampon
- Centrale photovoltaïque au sol avec batteries/onduleur
- Pépinière / ombrière, compost, chemins de circulation
- Zones de cultures : bananier plantain, manioc, papayer, gombo, arachide, maïs
- Haie vive multicouche, muret, clôture et chemin de terre voisin

## Contrôles

### Maquette 3D

- **Clic + drag** : tourner la caméra autour du terrain
- **Molette** : zoomer / dézoomer
- **Clic sur une zone** : ouvrir la fiche technique
- **Boutons de phase** : afficher les zones au fil du chantier
- **Boutons de vue** : vue d'ensemble, vue de dessus, vue habitat

### Rendu 4K

- **Zoom + / Zoom −** : agrandir ou réduire la composition
- **Drag** : déplacer la vue
- **Animation** : activer/désactiver un mouvement cinématique lent
- **Repères cliquables** : ouvrir les fiches techniques des installations
- **Maquette 3D tous angles** : revenir à la version WebGL pour consulter le site sous plusieurs angles
